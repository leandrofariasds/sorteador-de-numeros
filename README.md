# 🎲 Sorteador de Números

Aplicação web responsiva para realizar sorteios de números aleatórios de forma simples e rápida.

## ✨ Funcionalidades

- Definir a quantidade de números sorteados.
- Configurar o intervalo mínimo e máximo.
- Ativar ou desativar a repetição de números.
- Visualizar os resultados com animações.
- Copiar os números sorteados.
- Validar os dados antes do sorteio.
- Interface responsiva para desktop e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## 🚀 Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/LEANDROFARIASDS/sorteador-de-numeros.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd sorteador-de-numeros
   ```

3. Abra a pasta no Visual Studio Code.
4. Execute o arquivo `index.html` com a extensão Live Server.

É necessária conexão com a internet para carregar o Bootstrap e os ícones via CDN.
